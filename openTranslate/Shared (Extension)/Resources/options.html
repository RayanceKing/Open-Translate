视频字幕

为网页视频加载双语字幕：自动读取 YouTube 的字幕轨或页面里的 <track>，按播放进度实时显示原文与译文。

视频开始播放时自动加载字幕轨。单个页面上可以用快捷键临时开关。

在字幕后面加一层半透明黑底，画面明亮时更易读。

在视频页面切换双语字幕。

支持范围
  • YouTube：读取视频自带的字幕轨（优先人工字幕，其次自动字幕），在播放器内叠加双语字幕。
  • 原生 <track>：页面上带 WebVTT 字幕轨的 HTML5 播放器。
  • 没有字幕轨的视频（例如直播、纯音乐）无法生成字幕，需要站点自身提供文本。
  • 字幕同样走翻译缓存，同一段字幕不会重复请求。

漫画模式

用支持视觉的 AI 引擎（OpenAI / Gemini / Claude）识别图片中的文字并翻译，在图片上叠加译文。适合漫画、扫描版截图等以图片承载文字的场景。

开启后，启用翻译时会额外扫描页面里的图片并尝试 OCR + 翻译。建议仅在漫画 / 图片站点开启。

负责识别与翻译图片文字。需要先在「翻译服务」里为该引擎填写 API Key。

使用须知
  • 仅支持 OpenAI、Gemini、Claude 这类多模态模型，其余引擎无法识别图片。
  • 图片需允许跨域读取（大多数图床支持），否则会跳过该图并提示。

翻译服务

每个引擎独立保存密钥。点击「使用」即可切换为当前引擎，点击「测试」可用一句英文验证连通性。

适用于 OpenAI、DeepSeek、Gemini、Claude 等引擎的提示词模板。密钥在「翻译服务」中填写；术语库在独立设置页中管理。

可用变量：{{target}} 目标语言、{{source}} 源语言。

术语库

固定特定词汇的译法，让同一术语在全文中保持一致。修改后，重新翻译页面即可应用。

AI 翻译会参考当前文本命中的术语；模型不一定始终遵守指定译法。

Google、Microsoft 等不使用 AI 术语提示词。开启后使用占位符替换，可能影响译文自然度；占位符损坏时回退为普通翻译。

内置领域库

按目标语言匹配；通用条目可用于所有语言。同名词条按勾选先后优先使用，取消后重选可调整顺序。

没有匹配的术语库，试试其他关键词。

自定义术语

仅对没有单独指定语言的条目生效；CSV 中的 tgt_lng 可为每条术语指定语言。

每行「原文 = 译文」，或使用 source,target,tgt_lng 格式的 CSV。自定义优先于领域库；空译文表示保留原文。匹配不区分大小写，长词优先。

导入将替换当前自定义术语。导出会为表格公式风险添加安全前缀，使用本工具重新导入时会自动还原。

隐私与安全

翻译请求直接从浏览器发往你选择的引擎，没有中间服务器，也没有任何统计数据上报。

在文本离开浏览器之前，把邮箱、电话号码、常见 API Token 替换为占位符，翻译返回后再还原。建议保持开启。

翻译过的段落会暂存在浏览器会话内存里，刷新页面、切换标签页或后台从休眠中唤醒都无需重新请求。缓存不写入磁盘，关闭浏览器即清空，条目最多保留 12 小时。缓存只保存译文，不保存原文。

这些数据会去哪里？
  • Google / MyMemory：请求发往其公共翻译端点，会被对方记录。
  • DeepL / Microsoft / LibreTranslate：只发送到你在设置里填写的服务。
  • AI 引擎：整段文本会作为提示词发给模型提供方，请勿在敏感页面使用。
  • 所有 API 密钥保存在系统的钥匙串（Keychain）中，由系统加密、仅本机可读，且不会随 iCloud 同步到其他设备。
  • 通用设置通过 iCloud 键值存储在登录同一 Apple ID 的 iPhone / iPad / Mac 间同步；密钥不会进入同步。
